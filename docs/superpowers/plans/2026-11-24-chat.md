# Chat (Sagen + Welt) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spieler chatten im Kanal Sagen (≤ 50 m, mit Sprechblase) und Welt (alle), am Desktop per Fenster unten links, mobil per Chat-Knopf und eigenem Fenster.

**Architecture:** Eigene Colyseus-Nachricht `chat` (Ansatz A). Gemeinsamer Code in `@nn/shared` säubert, kürzt und filtert Text. Der Server drosselt pro Spieler und verteilt gezielt (Welt an alle, Sagen nach Entfernung aus der Sim). Der Client hält einen Verlauf, zeigt ihn im DOM-Fenster bzw. Mobil-Sheet und hängt Sagen-Zeilen als Canvas-Sprite-Blasen an die Figuren.

**Tech Stack:** TypeScript, Colyseus (Server + `@colyseus/sdk`), three.js, Vitest, Playwright (Check-Skript).

**Spec:** `docs/superpowers/specs/2026-11-24-chat-design.md`

## Global Constraints

- Texte im Spiel auf Deutsch; Code-Kommentare auf Englisch wie im Rest des Repos.
- `CHAT_MAX_LEN = 120` Codepoints; zusätzlich höchstens `CHAT_MAX_BYTES = 400` UTF-8-Bytes (Abstand zu `MAX_MESSAGE_BYTES = 512`, sonst Kick).
- `SAY_RANGE_M = 50` (horizontal, x/z).
- Drosselung: 5 Nachrichten Vorrat, danach 1 pro 2000 ms; kein Kick beim Chatten, auch nicht bei falscher Form.
- `PROTOCOL_VERSION` = 4.
- Start-Kanal Sagen; Verlauf 50 Zeilen; Desktop-Fenster 8 Zeilen, blendet nach 15 s ohne Aktivität aus.
- Systemtexte exakt: `Nicht so schnell.` und `Niemand in der Nähe hat dich gehört – /w für den Weltchat.`
- Server-Log ohne Nachrichtentext.
- Offline: kein Chat (kein Fenster, kein Knopf).
- Kein Versions-Bump in `package.json` (das passiert beim Release, siehe AGENTS.md).

## Review Focus

1. **Tippen bewegt die Figur nicht** – WASD/E/H/M/N/G/C/P im Eingabefeld dürfen weder `Input` noch andere globale Tasten-Listener (Debug-`P`) erreichen; beim Öffnen gedrückte Tasten werden losgelassen. → Test in Task 5.
2. **Emoji- oder Umlaut-lange Nachricht** – 120 Emojis sind 480 Byte: muss auf ≤ 400 Byte gekürzt werden, ohne ein Zeichen zu zerschneiden, und darf nie zum Kick führen. → Tests in Task 1 und Task 3.
3. **Sprecher geht, während die Blase steht / Sprecher außer Sicht** – Blase verschwindet ohne Fehler; Weltzeile eines Gegangenen zeigt den mitgeschickten Namen. → Test in Task 6.
4. **Reconnect** – nach einem Verbindungsabbruch funktioniert Chat weiter (Handler hängen am selben Room-Objekt); Nachrichten während `away` werden nicht gesendet. → Test in Task 3 (away-Seat bekommt nichts).
5. **Nur Leerzeichen / unsichtbare Zeichen / Zeilenumbrüche** – wird nicht gesendet bzw. vom Server verworfen; Zeilenumbrüche werden zu Leerzeichen. → Tests in Task 1 und Task 4.
