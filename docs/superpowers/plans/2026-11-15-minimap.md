# Minimap und Nippes-Karte Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mitdrehende Minimap oben rechts mit Straßennamen-Zeile und eine große, zoom- und verschiebbare Nippes-Karte auf Taste M.

**Architecture:** Die Pipeline schreibt Vektordaten (`world/map.json`: Straßen mit Namen, Gebäudegrundrisse, Grün, Plätze, Tram, Haltestellen, Grenze). `@nn/shared` definiert Typ und Validator. Der Client zeichnet mit Canvas 2D: reine Logik (Ansicht/Projektion, Raster-Index, aktuelle Straße, Labelplatzierung) in `apps/client/src/map/`, darüber zwei dünne DOM-Klassen (Minimap, große Karte) und die Verdrahtung in `game.ts`/`main.ts`.

**Tech Stack:** TypeScript, Canvas 2D, Vitest (Node-Umgebung, kein DOM in Tests), Playwright-Screenshot-Skript.

**Spec:** `docs/superpowers/specs/2026-11-15-minimap-design.md`

## Global Constraints

- Koordinaten lokal, x Osten, z Süden (m). Heading: Blick entlang (sin yaw, cos yaw).
- Keine Änderung an `manifest.json`, Chunks, `collision.bin`, `roadgraph.json`, `osm.ts`, `manifest.ts`. Neu committete Weltdatei: nur `apps/client/public/world/map.json`.
- `map.json` wird separat geladen, nicht über das Manifest. Ladefehler → Spiel läuft ohne Karte, Minimap ausgeblendet.
- HUD-Stil: DOM/CSS, dunkler Grund, Akzent `#f2c46b`, `font-family: system-ui`. Texte auf Deutsch.
- Kein Größenbudget für `map.json`.
- Minimap dreht sich nach `follow.yaw` (im Fly-Modus nach `fly.heading`, Position = Kamera); große Karte nach Norden.
- Karte offen: keine Steuereingaben; im Auto rollt das Auto weiter (Gas 0, Lenkung 0, keine Bremse, keine Handbremse). E/R/Space wirken nicht; Maus verschiebt, Mausrad zoomt. M oder Pointer-Lock-Verlust (Esc) schließt.
- `CONTROLS_HINT` bekommt „M Karte“.

## Review Focus

1. Tastendrücke während offener Karte (E, Space, R) dürfen nach dem Schließen nicht nachträglich auslösen → Task 6 testet `MapMode.close()` + `input.clearPresses()`-Pfad.
2. Straßenname flackert an Kreuzungen oder bleibt kleben, wenn man weit weg ist → Task 3 testet Hysterese und Abbruch über 25 m.
3. Kopfstehende oder überlappende Labels auf der großen Karte → Task 4 testet Winkelbereich und Überlappung.
4. Zoom/Pan läuft aus Nippes heraus oder zoomt ins Unendliche → Task 3 testet `clampView`.
5. Karte öffnen ohne Pointer Lock (Maus frei): Karte geht auf, Pan/Zoom erst nach Klick (Lock); Lock-Verlust schließt nur, wenn die Karte offen ist → Task 6 testet `MapMode.onLockChange`.

### Task 3: Kartenlogik – Ansicht, Raster-Index, aktuelle Straße

**Files:**
- Create: `apps/client/src/map/view.ts`, `apps/client/src/map/view.test.ts`, `apps/client/src/map/grid.ts`, `apps/client/src/map/grid.test.ts`, `apps/client/src/map/street.ts`, `apps/client/src/map/street.test.ts`

**Interfaces:**
- Consumes: `MapData`, `MapRoad` (Task 1).
- Produces:
  ```ts
  // view.ts – Bildschirm: Ursprung oben links, (w/2, h/2) = (cx, cz)
  export type MapView = { cx: number; cz: number; scale: number; rot: number; w: number; h: number }; // scale px/m; rot 0 = Norden oben
  export function rotForYaw(yaw: number): number;                 // Minimap: Blickrichtung nach oben
  export function worldToScreen(v: MapView, x: number, z: number): { sx: number; sy: number };
  export function screenToWorld(v: MapView, sx: number, sy: number): { x: number; z: number };
  export function zoomBy(v: MapView, notches: number): MapView;   // Faktor ZOOM_STEP pro Raste, um die Mitte; positive Rasten (deltaY > 0) zoomen heraus
  export function panBy(v: MapView, dx: number, dy: number): MapView; // Karte folgt der Maus (Inhalt bewegt sich mit dx/dy)
  export function clampView(v: MapView, b: MapData['bounds']): MapView;
  export const ZOOM_STEP = 1.25, MAX_SCALE = 4;
  // grid.ts
  export class MapGrid { constructor(data: MapData, cell?: number /* = 100 */); query(minX: number, minZ: number, maxX: number, maxZ: number): MapItems }
  export type MapItems = { roads: number[]; buildings: number[]; greens: number[]; squares: number[]; tram: number[] }; // Indizes in MapData, ohne Duplikate
  // street.ts
  export class StreetTracker { constructor(data: MapData, grid: MapGrid); update(x: number, z: number): string } // '' = keine
  ```

- [ ] **Step 1: Tests** `view.test.ts`:

  - `clampView limits zoom` → `scale` wird auf [`fit`, `MAX_SCALE`] begrenzt, `fit = min(w / (maxX − minX), h / (maxZ − minZ))`.
  - `clampView keeps the centre inside bounds` → cx/cz außerhalb wird auf `bounds` gesetzt.

### Task 4: Labelplatzierung

**Interfaces:**
- Consumes: `MapView`, `worldToScreen` (Task 3), `MapData`.
- Produces:
  ```ts
  export type Label = { text: string; sx: number; sy: number; angle: number; kind: 'road' | 'square' | 'stop' }; // angle in rad, Mitte des Texts
  export function placeLabels(data: MapData, items: MapItems, v: MapView, measure: (text: string) => number): Label[];
  export function minScaleFor(kind: string): number;
  ```

Regeln (feste Werte):
- Straßen nach Wichtigkeit: `primary`/`secondary` immer; `tertiary`/`residential`/`unclassified` ab 0,6 px/m; alle anderen benannten Wege ab 1,5 px/m. Plätze (nur benannte) ab 0,8 px/m, Haltestellen ab 1,0 px/m.
- Straßenlabel sitzt auf dem längsten Teilstück (Bildschirmlänge) einer Straße, dessen Länge ≥ 1,2 × Textbreite ist; Mittelpunkt dieses Stücks; Winkel entlang des Stücks, normalisiert auf (−π/2, π/2] (nie kopfüber).
- Reihenfolge: Haltestellen, Plätze, dann Straßen nach Rang (primary zuerst), innerhalb des Rangs nach Länge absteigend. Ein Label, dessen gedrehte Box (Textbreite × 14 px, plus 4 px Rand) eine schon platzierte schneidet, entfällt. Derselbe Straßenname höchstens alle 300 px.

- [ ] **Step 1: Tests** (`measure = (t) => t.length * 7`):
  - `never upside down` → Straße von rechts nach links gezeichnet: `angle ∈ (−π/2, π/2]`.
  - `drops overlapping labels` → zwei parallele Straßen 3 m auseinander bei scale 1: nur ein Label.
  - `hides minor roads when zoomed out` → `footway` mit Namen bei scale 1 → kein Label, bei scale 2 → Label.
  - `skips segments shorter than the text` → kurze Straße (10 m) bei scale 1 → kein Label.
  - `same name repeats only far apart` → lange gerade Straße aus vielen OSM-Ways mit gleichem Namen über 2000 px → Labels mindestens 300 px auseinander.
  - `unnamed squares get no label`.
